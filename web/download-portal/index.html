Built for signal, not noise

Everything you need to find the chain.

Detection, correlation and response in one desktop app. No cluster to operate, no data lake to feed.

Attack-chain correlation

Recon, brute force and successful login from one source become a single critical incident, not three unrelated alerts.

SOAR-Lite playbooks

Match Critical incidents and preview firewall or email actions. Dry-run by default, with dedupe and per-incident limits.

Real logs, real formats

Ingest pfSense, OPNsense, UFW, Linux auth, SSH and web access logs through files, syslog or the HTTP agent.

Local-first by design

Logs, alerts and incidents stay in %LOCALAPPDATA%\SIEM. No telemetry, no hosted backend.

Triage dashboard

Severity, status and time filters; incident detail with raw alert context; acknowledgement and assignment built in.

Guided Windows install

One installer creates the service, firewall rules and desktop shortcut. First launch generates a local admin account.

From detection to response

Respond on your terms.

SOAR-Lite is intentionally small and auditable. Playbooks are plain YAML, scoped to Critical incidents by default, and run at most once per incident. Start in dry-run, inspect the exact command, then enable it.

01

Match the incident

Severity, rule names, categories, correlation rules or alert count.

02

Preview the response

Dry-run renders every placeholder and records the intended command and recipients.

03

Act safely

Run argv-based commands without a shell, or reuse your existing SMTP settings for email.

Read the deployment notes
config/playbooks.yaml
dry-run 
enabled: true
dry_run: true
max_runs_per_incident: 1

playbooks:
  - id: "critical-block-source"
    match:
      severities: ["critical"]
    actions:
      - type: "command"
        command:
          - "iptables"
          - "-I"
          - "INPUT"
          - "-s"
          - "{src_ip}"
          - "-j"
          - "DROP"
        require: ["src_ip"]
        shell: false

      - type: "email"
        to: ["soc@example.com"]
        subject: "[SOAR] {severity} {incident_id}"
Command failures never interrupt the detection pipeline.

Install in minutes

Your SIEM. Your machine.

The Windows installer sets up the desktop app, background service and firewall rules. The first launch creates an admin account and writes the password to a local file.
